문의 처리에 필요한 정보

항목목적
이름 또는 별칭, 이메일, 문의 유형, 유형별 필수 질문상담 적합성, 전문가 참여, 기업 채용 문의 검토와 회신
추가로 작성한 경험·가능 시간·희망 시점 등 선택 항목문의 내용의 구체적인 검토

상담 문의의 필수 질문은 현재 업무·상담 주제·핵심 질문, 전문가 문의는 경험 분야·담당 업무·상담 주제·방식, 기업 문의는 팀 소개·직무·필요 경험입니다. 선택 항목을 적지 않아도 접수할 수 있습니다.

회원과 전문가 등록·상담

회원가입 시 이름·이메일·가입 유형·비밀번호의 단방향 해시(원문 비밀번호는 저장하지 않음)를 저장합니다. 전문가가 직접 입력한 표시 이름·산업·직무·경력·상담 주제·방식·가능 시간·상담료는 승인 후 공개합니다. 소속명은 공개에 동의한 경우만 공개하며, 자기소개·업무 설명에 본인이 적은 소속이나 사업명도 공개될 수 있으므로 제출 전 확인해야 합니다.

선택 등록한 이력서 PDF는 경력 확인 목적으로 본인과 권한 있는 운영자만 접근하며 공개하지 않습니다. 회원은 등록 화면에서 PDF를 삭제할 수 있습니다. 계정·프로필 삭제는 문의처로 요청할 수 있고 본인 확인 후 처리합니다. 회원 정보는 계정 유지 중 보관하며, 삭제 요청 시 다른 법령상 보존 의무가 있는 경우를 제외하고 처리합니다.

상담 신청 시 표시 이름과 질문을 선택한 전문가에게 제공합니다. 일정·메시지·상담 결과는 상담 당사자와 운영자가 진행 관리 목적으로 접근합니다. 채용 기업에 제공하지 않으며, 기업 제공은 별도 확인 절차를 거칩니다. 일반 문의의 보관 기준과 회원·상담 기록의 보관 기준은 구분합니다. 상담 기록은 완료·취소 후 분쟁 대응과 서비스 확인을 위해 최대 1년 보관하는 기준으로 운영하며, 삭제 요청은 문의처에서 검토합니다.

이력서로 전문가 참여 신청

이력서 참여 신청 시 이름, 가입 이메일, PDF 이력서를 필수로 처리하고 전화번호와 희망 상담 주제는 선택으로 받습니다. 운영자가 경력을 검토하여 전문가 소개 초안을 작성하고 참여 조건을 안내하는 데 사용합니다. 초기 참여 신청 단계에서는 AI 분석 서비스로 이력서를 보내지 않습니다. 원본은 신청자 본인과 권한 있는 운영자만 열람합니다.

이력서 접수만으로 전문가 소개를 공개하지 않습니다. 운영자가 작성한 초안을 본인이 확인·수정하고 검토 신청한 뒤 운영자가 승인해야 공개됩니다. 소속명 공개도 본인이 선택합니다. 신청 정보는 회원·프로필의 기존 보관 기준과 미국 Railway 해외 보관 안내를 따릅니다. 동의를 거부하면 이력서 접수는 진행되지 않으며 직접 소개를 작성하거나 운영자에게 문의할 수 있습니다.

공개·상담 이력이 없는 신청은 참여 신청 화면에서 철회할 수 있습니다. 철회하면 원본 PDF와 작성 중인 소개, 선택 연락처·희망 주제를 삭제하고 접수번호·계정 연결·동의 및 처리 상태는 회원 유지 기간 동안 보관합니다. 공개·상담 이력이 있는 경우 개인정보 담당자에게 요청해주세요. 수동 백업 사본은 아래 백업 삭제 기준에 따라 별도로 처리합니다.

선택 기능: 이력서로 소개 초안 만들기

자동 작성 기능을 선택하고 별도로 동의하면, 선택한 PDF 파일 전체를 OpenAI API로 전송하여 경력·전문 분야·상담 주제의 초안을 생성합니다. 파일에 포함된 개인정보도 전송되므로 분석에 불필요한 주민등록번호·주소·서명·제3자 연락처는 먼저 제외해주세요. 이용하지 않아도 전문가 소개를 직접 작성할 수 있습니다.

전송은 생성 버튼을 누를 때 서버에서 암호화된 통신으로 이루어집니다. 분석용 파일과 생성 결과는 이 기능만으로 울림의 데이터베이스에 저장하지 않습니다. 동의 일시와 안내 버전은 회원 동의 기록에 남습니다. 초안을 확인하고 저장·검토 신청한 경우에만 프로필로 저장되며, 별도 비공개 첨부를 선택한 PDF에는 기존 보관 기준이 적용됩니다.

외부 처리 제공자는 OpenAI이며, 해외 서버에서 처리될 수 있습니다. API의 응답 저장 옵션은 끄지만 제공자의 보안·오남용 방지 보관까지 즉시 삭제된다는 의미는 아닙니다. 기본 API 오남용 모니터링 기록은 최대 30일 보관될 수 있으며, 법적 의무 등에 따른 예외가 있습니다. 자세한 내용은 OpenAI 데이터 처리 안내를 확인해주세요. 전송된 파일의 처리 관련 문의와 동의 철회는 개인정보 담당 이메일로 요청할 수 있습니다.

자동 작성 결과는 오류가 있을 수 있어 직접 확인·수정해야 합니다. 생성만으로 전문가를 등록하거나 공개하지 않으며, 회사명 공개와 상담 조건은 본인이 선택합니다.

보관과 삭제

문의 처리 중에는 검토와 회신을 위해 보관하고, 종료 처리 후 90일 이내 삭제합니다. 문의 정보와 내부 검토 기록은 권한 있는 운영자만 접근합니다. 관리자 로그인 세션은 최대 8시간 유지합니다.

선택과 권리

수집·이용 동의를 거부할 수 있으며, 이 경우 온라인 문의 접수가 제한됩니다. 열람·정정·삭제·동의 철회는 아래 이메일로 요청할 수 있습니다. 본인 확인 후 처리합니다.

별도 동의 없는 공유 없음

문의 접수 동의를 광고 수신이나 채용 후보자 등록 동의로 사용하지 않습니다. 기업에 후보자 정보를 전달하려면 대상과 공유 범위를 별도로 확인합니다. 현재 자동 이메일 발송·분석 추적·외부 광고 도구는 사용하지 않습니다.

정보 관리 책임과 해외 보관 안내

개인정보 처리 주체는 알림앤울림입니다. Railway Corporation은 사이트 실행과 데이터 저장에 사용하는 호스팅 제공업체입니다. 프로필 공개 범위와 상담 운영은 울림이 관리합니다. 미국에 보관된다는 사실이 경력과 이력서를 누구나 볼 수 있다는 뜻은 아니며, 공개 프로필과 비공개 원본은 서로 다른 접근 권한을 적용합니다.

울림은 웹사이트 실행과 데이터 보관을 위해 Railway의 호스팅 서비스를 이용합니다. 현재 서비스 실행 지역은 미국(US East)입니다. 신규 가입과 문의 접수 시 아래 국외 이전 안내를 확인하고 별도로 동의하도록 합니다.

운영자 수동 백업

운영자는 장애 복구를 위해 회원·경력·PDF·상담·문의가 포함된 비공개 백업을 내려받을 수 있습니다. 로그인 세션은 백업에서 제외합니다. 백업 파일 자체는 암호화되지 않으므로 운영자는 접근을 제한한 암호화 저장소에 보관해야 합니다. 수동 사본은 최대 30일 보관 후 운영자가 삭제하는 기준을 적용하며, 삭제·동의 철회 요청 처리 시 사본도 함께 확인합니다. 백업으로 복원하는 경우 이미 처리한 삭제 요청을 재적용합니다. 현재 자동 백업 예약은 제공하지 않습니다.

안전한 처리

관리자 인증·접근 제한을 적용하고 비밀번호는 공개하지 않습니다. 세션 유지를 위한 필수 쿠키만 사용합니다. 서비스 호스팅과 처리 방식이 변경되면 관련 안내를 갱신합니다.
