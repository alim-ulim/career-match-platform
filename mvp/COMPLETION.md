# 울림 전문가 등록·상담 MVP 구현 기록

2026-10-21

회원(상담 고객/전문가) 가입·로그인, 전문가 경력과 상담 주제 등록, 선택 PDF(3MB), 소속명 공개 선택, 초안·검토 신청, 운영자 승인/보완 요청, 승인 전문가 검색과 상세 프로필을 구현했습니다. 미등록 전문가나 사용자를 실제 참여자로 표시하지 않습니다.

상담 신청→전문가 수락/거절→당사자 메시지→전문가 일정 제안→고객 확정→상담 후 결과 기록이 연결됩니다. 운영자는 고객 동의를 확인한 뒤 재매칭할 수 있습니다. 상담과 이력서는 접근 권한을 검사하고, 승인 후 프로필 변경은 공개 목록에서 내려 재검토합니다.

자동 통합 테스트 18개 통과. 브라우저에서 별도의 QA DB로 전문가 가입·경력 제출·운영자 승인·공개 목록 및 소속 비공개를 확인했습니다. 실제 사용 DB에는 QA 전문가를 넣지 않았습니다. 이력서 원본과 관리자 비밀번호는 소스 패키지에 포함하지 않습니다.

실행: http://127.0.0.1:8766/ · 전문가 등록: /expert/register · 운영자: /admin → /admin/platform

현재는 로컬 구현 완료 단계입니다. GitHub push·외부 공개 배포는 하지 않았습니다. 지인 모집에 사용할 공개 URL은 HTTPS·영속 저장소를 갖춘 운영 배포 후 확정해야 합니다. 자동 이메일 인증/알림·비밀번호 재설정 메일·온라인 결제·화상 통화·채용 계약과 수수료 정산은 미구현입니다. 실제 기기(iPad) 검증도 하지 않았습니다.

전달 소스는 outputs/ulim-site와 ulim-site-source.zip, 기존 저장소의 로컬 브랜치 mvp/ 사본입니다. 설치·운영 방법과 제약은 README.md를 참조하세요.


## 2026-10-22 배포 준비 보완
Docker 저장 폴더 초기화 후 node 사용자 실행, 고정 영속 경로 /data/ulim, 원점/운영 경로 검증, .env 형식과 비밀 파일 제외, SQLite 스냅샷 도구·복원 절차를 추가했다. 통합 테스트 21개 통과. Railway 장애로 공개 배포는 미진행. Docker 이미지 빌드 도구가 없어 실제 컨테이너 볼륨 검증도 남아 있다.
