# 이력서 기반 전문가 소개 초안

PDF 선택 → 선택적 AI 분석 동의 → 초안 미리보기 → 입력란 적용·수정 → 검토 신청 → 기존 운영자 승인.

자동 작성: 한 줄 소개, 자기소개, 산업·직무, 상담 질문 제안, 주요 경력. 총 경력 연수는 문서에서 명확한 경우만 옮기고 나머지는 직접 입력한다. 표시 이름, 상담료·시간·방식은 변경하지 않는다. 회사명은 경력의 별도 필드에만 두도록 지시하며, 적용할 때 회사 공개와 참여 확인 체크를 해제한다. 사용자는 공개할 문구 전체를 확인한다.

생성 요청은 프로필·공개 상태·기존 첨부 PDF를 변경하지 않는다. 업로드 PDF는 메모리에서 분석 요청으로 전달하며 이 기능의 별도 영속 저장은 없다. 사용자가 따로 선택한 기존 비공개 첨부 기능은 유지한다. AI 응답은 허용된 필드만 검사해서 전달하고 HTML로 실행하지 않는다.

## 활성화

서버 환경변수에 `OPENAI_API_KEY`, `RESUME_AI_MODEL`(PDF와 Structured Outputs 지원 모델), `RESUME_AI_ENABLED=true`를 설정한다. 기본은 비활성이고 세 항목이 모두 있어야 화면에서 생성 버튼이 활성화된다. 키를 클라이언트·Git·대화에 입력하지 않는다. OpenAI API 호출에는 별도 사용료가 발생한다.

배포 전 운영 계정의 실제 외부 처리 지역·계약·보관 설정을 확인해 `/privacy#resume-ai` 안내를 확정한다. 현재 문구는 일반 API 데이터 처리 기준이다. 응답 저장은 `store:false`이며 제공자의 오남용 모니터링 보관까지 없다고 주장하지 않는다. `/v1/files`에 파일을 업로드하지 않는다.

새 모듈은 Dockerfile에 포함했다. 실행은 기존 `npm start`, 검증은 `npm test`. API 키 없는 테스트는 모의 응답을 사용한다. 실제 AI 품질·한국어 PDF·스캔본·응답시간은 별도 테스트용 이력서와 운영 계정으로 점검해야 한다. 공개 서비스에는 아직 배포하지 않았다.

## 제한과 실패 처리

- PDF 최대 3MB. Word/HWP는 PDF 변환 후 사용. 암호·손상·읽을 수 없는 문서는 다시 업로드하거나 수동 작성.
- 계정당 시간당 5회, 서버 프로세스 전체 시간당 50회, 동시 외부 호출 3회. 여러 인스턴스로 확장하면 공유 제한 저장소가 필요하다.
- 서버 분석 제한 60초, 화면 요청 제한 75초. 오류 원문과 API 키를 사용자에게 노출하지 않는다.
- AI 제안은 사실 검증이나 전문가 자격 인증이 아니다. 원문에 없는 내용이 완전히 배제된다고 보장하지 않으며 본인 확인·운영자 검토를 유지한다.

공식 근거: [PDF 입력](https://developers.openai.com/api/docs/guides/file-inputs), [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs), [데이터 처리](https://developers.openai.com/api/docs/guides/your-data).

## 이번 검증 결과 · 2026-11-04

- 사용자 확인: API 계정·결제 설정 미준비. 실제 외부 AI 호출·비용 발생·공개 배포 없이 로컬 구현까지만 완료.
- 새 서버 테스트 4개 통과: 권한·CSRF·선택 동의, 생성 시 기존 데이터 보존, 호출 한도, 미설정·실패·거절·불완전 응답 처리, 구조 검사.
- Edge 브라우저: 테스트용 모의 AI로 가입→파일 선택→초안 미리보기→덮어쓰기 취소/확인→상담 조건 유지→직접 경력 연수 입력→검토 신청(pending) 확인. 모바일 390px 가로 넘침 없음, 브라우저 오류 없음.
- 전체 28개 중 25개 통과. 백업 관련 3건 실패는 아직 미해결이다. 두 건은 Windows 파일 권한 비트가 POSIX 기대값과 달라 이전 HEAD 코드에서도 재현했다. 한 건은 다운로드 테스트 직후 임시 백업 정리 검사로, 이전 HEAD 실행에서는 통과했으나 현재 실행에서는 실패했다. 이번 기능과 관련 없는 백업 코드는 수정하지 않았다. 전체 테스트 통과로 보고하지 않는다.
- 실제 모델의 추출 품질·문서별 정확도·비용·지연은 API 연결 후 검증 필요.
